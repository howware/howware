# Security

Report vulnerabilities, or any way in which the template or the skills could expose someone's personal data,
**privately**: Security → Report a vulnerability, or
https://github.com/proteo5/howware/security/advisories/new.

Never include real personal data in a report, an issue or a pull request. Describe the type of data and where it
appeared, not its value.

Problems in a specific howware go to that howware's repository; problems in the memory go to
[Long-Term Memory for AI](https://github.com/proteo5/long-term-memory-for-AI).

This is a personal project maintained in spare time: reports are answered as soon as possible, with no guaranteed
deadline. Exposure of personal data takes priority over any other change.
